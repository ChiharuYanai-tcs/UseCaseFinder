# ユースケース提案 AI エージェント

テクノロジーキーワードから最新の論文・ニュースを調査し、革新的なユースケースを提案するAIエージェントです。

## 特徴

- **論文検索**: Semantic Scholar APIで最新論文を取得
- **ニュース検索**: RSS/Webから技術記事を収集
- **AI分析**: Claude APIで情報を分析しユースケース提案
- **キャッシュ機能**: 同じキーワードの再検索を効率化
- **レポート出力**: Markdown形式で結果を保存

## セットアップ

### 0. 環境の用意
venv 環境で以下を実行することをおすすめします。

### 1. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. 環境変数の設定

`.env`ファイルを作成し、Claude APIキーを設定:

```
ANTHROPIC_API_KEY=your_api_key_here
```

## 使い方

### 基本的な使用方法

```bash
python main.py
```

プロンプトが表示されたら、調査したいキーワードを入力してください。

### 例

```
キーワードを入力してください: Digital Twins
```

## 出力

結果は`outputs/`ディレクトリに Markdown 形式で保存されます。

- 技術トレンド分析
- 実用可能なユースケース（3-5個）
- 実装時の注意点

## 設定

`config.py`で以下の設定をカスタマイズ可能:

- 検索件数
- キャッシュ有効期間
- Claude モデル設定
- 出力フォーマット
